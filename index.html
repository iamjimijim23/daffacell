🗄️ Supabase Cloud Sync
Simpan & sinkronisasi data ke cloud secara otomatis
⚪ Belum dikonfigurasi
📋 Cara Setup (sekali saja):
1. Daftar gratis di supabase.com
2. Buat project → Settings → API → copy URL & anon key
3. Buka SQL Editor → paste SQL di bawah → Run
4. Masukkan URL & Key di form ini → klik Simpan & Test
📋 SQL — JALANKAN DI SUPABASE → SQL EDITOR
create table if not exists daffacell_data (
  id           text        primary key,
  data         jsonb       not null,
  updated_at   timestamptz default now()
);
alter table daffacell_data enable row level security;
drop policy if exists "allow_all" on daffacell_data;
create policy "allow_all" on daffacell_data
  for all to anon, authenticated
  using (true) with check (true);
Gunakan anon/public key, bukan service_role key
Kosongkan = ID otomatis. Isi sama di semua HP untuk sinkronisasi.
⚠️ Jika sync gagal: pastikan SQL sudah dijalankan, URL tanpa / di akhir, dan pakai anon key (bukan service_role).
